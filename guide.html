← WarLike Store

Store → Library → Engine

  1. Store : choisis un modèle, un sprite, une texture ou un son. Le catalogue et les fichiers sont hébergés par ce store indépendant.
  2. Ajouter à Library : le fichier et ses textures sont préparés, puis envoyés à WarLike Library. Une confirmation apparaît après vérification et enregistrement.
  3. Library : retrouve tes fichiers, classe-les et prépare leurs composants dans Prefab Studio.
  4. Engine : lance l’installation depuis Library. Le fichier est transféré réellement dans le navigateur qui héberge Engine.

Les fichiers de Library sont conservés localement dans le navigateur. Auteur, licence, source et empreinte SHA-256 accompagnent chaque import.

Import manuel

Si les fenêtres sont bloquées, utilise « Exporter pour Library », puis ouvre l’importeur Library et sélectionne le paquet JSON.
