WARLIKE ASSET STORE · OUTILS & PRESETS

Extensions pour les logiciels WarLike

Modules JavaScript réutilisables et ressources JSON pour Engine, Studio, Node, Monteur et MISC. Télécharge les vrais fichiers du dépôt, sans fausse installation.

Compatibilité : les modules ES sont utilisables dans un environnement JavaScript qui les importe explicitement. Les profils JSON sont des préréglages de référence : chaque application doit disposer d'un importeur compatible pour les installer. Aucun plugin VST, effet GPU ou fonction d'exécution n'est annoncé comme opérationnel sans intégration et test.
